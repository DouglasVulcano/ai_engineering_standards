What it is

From loose AI config to a versioned package

Instead of a different CLAUDE.md in every repo, one source of truth that any agent of any model applies the same way, on any project, in any language.

The specification

A complete, readable ai-engineering-standards.md: the single source of truth for the whole standard.

The skill

The same knowledge with progressive disclosure: it loads only the domain a task needs, and triggers on its own.

The scaffolder

One command adds real governance to a repo: templates, CODEOWNERS, a CI gate, agent guides, and the safety rails.

The standard

Four pillars, always in force

Applied whenever an agent starts, plans, or reviews work.

1

Workflow and governance

Issue-first, PR-driven. Every task is an Issue; every deploy is a PR that references it (Closes #N). Conventional Commits. Feeds a canonical AGENTS.md with a thin CLAUDE.md import.

2

Motion and UI/UX

Skeleton, lazy loading, and smooth enter, exit, loading, and progress states. Honor prefers-reduced-motion; animate only transform and opacity. Web Interface Guidelines.

3

Observability, quality, testing

OpenTelemetry to any backend, and an ordered capability gate: fmt, lint, typecheck, arch, deadcode, test, coverage, build. Unit, integration, and E2E with diff coverage. Stack-agnostic by design.

4

Arsenal

The right tool per task: shadcn-ui-mcp, 21st.dev Magic, chrome-devtools-mcp, design-motion-principles, web-design-guidelines, and humanizer, with a vetting checklist before adding any MCP.

Why it works

Advice you can enforce

The skill is guidance; CI plus branch protection are the authoritative gate. The package gives you both.

Governance scaffolder

Issue and PR templates, CODEOWNERS, a stack-aware CI gate, AGENTS.md plus a thin CLAUDE.md, and a safety deny-list. Idempotent, and it never overwrites without --force.

Arms the real gate

The scaffolder prints, and can apply, branch protection for your default branch, in both the classic API and the newer Ruleset model, and warns you off the common footguns.

Conservative hooks

Fail-open PreToolUse guards block clearly destructive Bash and edits to secret files, a deterministic in-session guardrail alongside the settings deny-list.

Stack-agnostic

Pillar 3 is a set of capability contracts, not a fixed toolset. A per-stack appendix maps each verb to JS/TS, Python, Go, Rust, JVM, and .NET.

Self-tested

A versioned eval suite and a verify.sh self-check keep the package honest. The repo dogfoods its own standard end to end.

Versioned, no drift

Shipped as a Claude Code plugin so teams update deliberately with claude plugin update. Model-agnostic through a canonical AGENTS.md.

The golden path

Zero to enforced governance

The value shows up when the whole path is in place, not just the skill.

Scaffold governanceRun scaffold.sh /path/to/repo to add templates, CODEOWNERS, a CI gate, agent guides, and the safety deny-list. Preview with --dry-run.
Fill AGENTS.md and CODEOWNERSAdd your stack and its gate commands, and set real code owners. The two things the scaffolder cannot guess.
Arm branch protectionRequire the verify check plus review on your default branch. Re-run with --protect (add --ruleset for the newer model) or apply the printed command.
