O problema

Bons padrões são fáceis de escrever e fáceis de ignorar

Agentes de IA só seguem as instruções que você dá. Deixadas a cargo de cada projeto, essas instruções se perdem.

Um setup diferente em cada repo

Cada projeto cria suas próprias instruções, então o mesmo assistente se comporta de um jeito em cada repositório.

Regras que ninguém verifica

Um documento de diretrizes é fácil de pular. Quando nada verifica, a qualidade cai aos poucos.

Configuração manual demais

Fazer certo significa montar templates, checagens e revisões na mão, de novo e de novo, em cada repo.

A solução

Um padrão compartilhado, instalado uma vez

Uma fonte única da verdade que qualquer agente de IA aplica do mesmo jeito, em qualquer projeto e linguagem.

Um guia claro

Uma especificação legível que define como o trabalho é planejado, construído, testado e entregue.

Uma skill que aplica

Ela se integra ao Claude Code e traz a regra certa no momento certo, carregando só o que a tarefa precisa.

Uma ferramenta de setup

Um comando adiciona os templates, as checagens e as proteções ao repositório pra você.

O que ele cobre

Quatro áreas, um padrão consistente

Aplicado sempre que um agente começa, planeja ou revisa um trabalho.

1

Como o trabalho flui

Toda mudança começa como um ticket e chega como um pull request revisado. Histórico claro, sem commits surpresa.

2

Como as telas se sentem

Telas fluidas: estados de carregamento, animações sóbrias e respeito às preferências de acessibilidade e de menos movimento.

3

Como a qualidade é mantida

Checagens consistentes de formatação, tipos, código morto e testes, em qualquer stack, antes de qualquer merge.

4

Quais ferramentas usar

Uma caixa de ferramentas selecionada que o agente usa, com uma revisão de segurança antes de adicionar algo novo.

Por que funciona

Orientação em que você pode confiar

O padrão é o conselho. As checagens e as regras de revisão do seu projeto são o que garantem, e a ferramenta de setup te ajuda a ativar isso.

Setup

Governança em um comando

Adiciona templates de issue e PR, code owners, um workflow de checagem, guias para o agente e regras de segurança. Nunca sobrescreve seus arquivos sem perguntar.

Garantia

Ajuda a ativar as proteções

Ele imprime, e pode aplicar pra você, as proteções de branch que exigem checagem e revisão antes de qualquer merge.

Segurança

Proteções sensatas

Bloqueia comandos claramente destrutivos e edições em arquivos de segredo enquanto o agente trabalha, uma rede de segurança simples.

Qualquer stack

Sem amarra a uma ferramenta

As checagens de qualidade são definidas como metas e mapeadas pra sua linguagem: JavaScript, Python, Go, Rust, Java ou .NET.

Confiança

Testado em si mesmo

O pacote se verifica a cada mudança, e este projeto roda no próprio padrão de ponta a ponta.

Distribuição

Versione e compartilhe

Distribuído como plugin do Claude Code, então o time inteiro fica na mesma versão, e funciona com qualquer agente que leia um arquivo de guia compartilhado.

Comece

FAQ

Perguntas comuns

O que é isso, em uma frase?

Um guia compartilhado para agentes de IA que você instala uma vez, para que eles planejem, construam, testem e entreguem código de forma consistente em todos os seus projetos.

Para quem é?

Para quem usa assistentes de IA como o Claude Code e quer resultado consistente, revisado e testado, seja um dev solo ou um time inteiro.

Preciso mudar minhas ferramentas ou linguagem?

Não. As checagens de qualidade são metas mapeadas para o seu stack atual, então funciona com JavaScript, Python, Go, Rust, Java, .NET e mais.

Ele muda meu repositório automaticamente?

Não. Ele prepara as peças e mostra os comandos; você decide quando ativar as checagens e as regras de revisão que garantem o padrão. Nada é mudado sem a sua confirmação.

Com quais agentes de IA funciona?

O plugin e o skill instalam no Claude Code. Para outros agentes (Cursor, Copilot, Codex), aponte-os para o AGENTS.md que a ferramenta de setup gera (ele importa o zeroth.md) e eles leem o mesmo padrão. O enforcement mora no seu repositório (CI mais branch protection), então vale igual seja qual for o agente que escreve o código.
